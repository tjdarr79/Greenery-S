COMMIT MESSAGE
--------------
Module offline detection, full alert parity, one-click Windows installer

Adds per-module offline detection to farm_bridge.py, published separately by
severity: environmental and output offline are crop emergencies, dosing offline
silently stops correction, input offline is only a data lapse. Detection uses
both the connected flag and last_update staleness, because a module can claim
connected while its data stops advancing and every reading downstream would
look plausible and mean nothing.

Brings the alert set to full parity with farmhand's built-in alerts by adding
the four that were missing: low air temperature, HVAC cooling stuck 24h, send
pump insufficient pressure, and module offline. Twenty automations total.

Adds a one-click Windows installer. Double-clicking INSTALL-FARM-BRIDGE.bat
takes a non-technical operator from a downloaded ZIP to a running bridge:
installs Python if needed, copies to C:\Farm, prompts for MQTT settings,
tests connectivity, and registers a SYSTEM startup task with restart-on-
failure. It refuses homeassistant.local and requires a numeric IP, reads the
password as a SecureString, ACLs the env file, and stops any previous bridge
before copying so an upgrade cannot silently leave old code running.

Adds tools/verify-repo.py to confirm a clone is complete before anyone relies
on it, and moves the diagnostic scripts into tools/.
