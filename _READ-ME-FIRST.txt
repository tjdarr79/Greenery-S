COMMIT MESSAGE
--------------
Map the 32-channel output board as read-only binary sensors

farm_bridge.py now publishes all 32 relay channels plus Task Mode Active,
Output Board Connected, and Relay State Mismatch. Anyone cloning this repo
gets the mapping already applied - no patch step.

Adds three automations: recirc pump stopped (gated on Task Mode), task mode
left on 6+ hours, and equipment not responding.

Documents the ch8 chiller-pump interlock and the ch23 permanent-manual
channel, both of which change how these sensors must be read.
